## Source facts and decision

AIResponse has legacy int InputTokens/OutputTokens; OpenAI-compatible JSON unmarshal cannot distinguish absent/null from zero, Claude int conversions discard pinned SDK field metadata, and Gemini UsageMetadata pointer does not establish presence of its scalar fields. Analyzer and existing UO receipt expressly report interface-values/presence-unavailable. Do not reinterpret those receipts or old cost logs during this tranche.

Complete an additive adapter boundary: AIResponse carries optional versioned usage-presence metadata with independently classified input/output counts. OpenAI/xAI use their actual existing raw response; Anthropic uses retained original JSON/field metadata; Gemini may use original SDK HTTP body only when already available. Without an actual raw/field-presence source, report presence unavailable; never marshal a typed SDK struct and claim that reconstruction proves wire presence. Do not enable a new HTTP capture option, intercept transport or retain provider content merely for this feature.

Pure parser/response-conversion tests use local serialized fixture bytes and pinned SDK decoding, not a mocked AI provider decision or real provider invocation. Existing ai tests use loopback httptest; only those inherited tests may open loopback sockets. No external API, real credentials, config, application data or DB. This establishes parsing and adapter mapping, not live provider behavior or AI governance.
