## Design and claim boundary

One engine-owned coordinator serves HTTP test-run/trigger, cron, after-sync, HTTP analysis agent and direct public Analyzer methods. Ownership is the tenant/job/run tuple plus an opaque local token, never a job-only cancel function. The implementation may choose its concrete API; all contracts below are mandatory.

The MCP `cqa_trigger_job` path currently returns a `triggered`/queued message without invoking Analyzer or a queue. It is not an execution entrypoint and is not evidence of admission. Correcting that existing placeholder needs a separate MCP work order; this tranche neither activates it nor endorses its queued claim. Preserve R021 permission regressions.

In one backend process, at most one owned execution per tenant/job exists from reservation through actual worker exit, including terminal persistence, notification and deferred cleanup. Different jobs/tenants remain independently runnable. A short checked MySQL admission transaction locks the tenant-scoped Job parent, checks running JobRuns and creates exactly one running row. Cooperating revised processes must serialize this database reservation; a stored running row without a local owner blocks new work. This is not a distributed lease: cross-process cancellation, crash recovery, takeover, mixed binary rollout and a global guarantee beyond the running-row admission interval are excluded. A terminal row can precede notification cleanup, so only the local coordinator protects that tail.

No schema/status additions, timeout-based reclaim, bulk cancellation, or terminal-row deletion to make admission succeed. Existing ambiguous/stale running rows fail closed. Recovery needs a separate work order. New short transactions that lock both Job and JobRun must use consistent Job -> JobRun order, with F03 finalizer adjusted only as necessary. Retain R002 conversation/run parent locks and child-delete guarantees; do not hold database locks through provider calls or worker joins. Document lock order and cancellation/terminal serialization.
